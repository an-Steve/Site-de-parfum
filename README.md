Bienvenue dans le dépôt du projet **Sillage d'Or**, une plateforme d'e-commerce simulant la vente de parfums de luxe.
Ce projet a été conçu pour établir une base solide et professionnelle pour une boutique en ligne, en utilisant un mélange de PHP pour le contenu dynamique et de JavaScript pour l'interactivité côté client (panier).

## 🚀 Vue d'Ensemble du Projet

Ce site vitrine et e-commerce intègre une architecture modulaire pour simuler une expérience d'achat complète, allant de la navigation produit à la gestion du panier.

### 💻 Technologies Utilisées

| Catégorie | Technologie | Rôle dans le Projet |
| :--- | :--- | :--- |
| **Côté Serveur** | **PHP** | Gestion du contenu dynamique (produits), traitement des formulaires (simulé), inclusion de fichiers (`header`/`footer`). |
| **Structure** | **HTML5** | Squelette de toutes les pages (Accueil, Catalogue, Panier, Compte). |
| **Design** | **CSS (Design Custom)** | Styles pour un look élégant et minimaliste, typique de la parfumerie de luxe. Intégration du Responsive Design. |
| **Interactivité** | **JavaScript (Vanilla JS)** | Gestion du Panier (Local Storage), mise à jour du compteur dans l'en-tête, interaction sur la page Panier (quantité, suppression). |
